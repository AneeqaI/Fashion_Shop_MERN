# Frontend – React Application

This folder contains the **frontend** of the full-stack MERN application.  
The user interface was developed using **React** and focuses on component-based design, state management, and user interaction.

## 🛠️ Technologies Used
- React
- JavaScript (ES6)
- HTML5
- CSS3
- Axios (for API requests)

## 📂 Folder Structure
client/
├── public/
├── src/
│   ├── components/
│   ├── pages/
│   ├── App.js
│   └── index.js
├── package.json
└── README.md

## 🚀 Features
- Responsive user interface
- Dynamic rendering using React components
- Communication with backend API using HTTP requests
- Modular and reusable component structure
