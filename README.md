# Full-Stack MERN Application

This repository contains a full-stack web application developed over a 12-week university project.  
The application was built using the **MERN stack** (MongoDB, Express.js, React, Node.js) and demonstrates end-to-end frontend and backend development.

## 👥 Team Collaboration
This project was completed collaboratively:
- **Frontend Development:** UI design, React components, and client-side logic
- **Backend Development:** API development, database models, and server-side logic (implemented by another team member)

## 🛠️ Tech Stack
- **Frontend:** React, JavaScript, HTML, CSS
- **Backend:** Node.js, Express.js, MongoDB
- **Architecture:** RESTful API with separated client and server structure

## 📁 Project Structure
- `/client` – Frontend React application  
- `/server` – Backend Node.js & Express API  

## 📚 Learning Outcomes
- Full-stack application architecture using MERN
- Collaborative development and role separation
- Client-server communication via REST APIs
- Structuring scalable frontend and backend codebases
